Barony

Git-native policy enforcement for AI coding agents.

Hypothesis
As multi-agent coding workflows scale, enterprise teams need git-native policy enforcement, persona charters and divergence tracking, not black-box prompt chains.
Result so far
A spec, a CLI called baron, and adapters for Claude Code, code-puppy and pydantic-ai. baron guard blocks denied actions before the tool runs, and every rule is labelled honestly as enforced or merely instructed. The first-party audit that motivated it measured 0.53 operational fidelity on a real pilot, with 18 of 40 handoffs left open. Published on PyPI. Barony now governs its own repository and governed the agent teams behind TrellisIQ and Shuttler.
Stack
Python CLI (baron), git hooks, LLM guardrails, markdown and git as the substrate

enCodr

Compile ideas into visual communication.

Hypothesis
A presentation is a compiled communication product. Keep the argument in reviewable structured source, and one source compiles into a ten-minute briefing or a forty-five-minute talk, for PPTX, web, PDF or video.
Result so far
Thesis, visual grammar, nine ratified architecture decisions, and a working prototype: a deterministic compiler that lowers, verifies and emits slides and checks every render in Chromium; API, CLI and browser editor over PostgreSQL; model adapters with spend reserved before dispatch; an agent loop that repairs deterministically first and escalates to a model only on a configured trigger. The prototype does not yet implement the whole thesis.
Stack
TypeScript, Fastify, PostgreSQL, Playwright and Chromium, zod, OpenAI, Anthropic and OpenRouter adapters
Functional MVP, live

TrellisIQ

Full-stack garden and crop analytics platform.

Dashboard, demo garden Garden detail Capture and analyze trellisiq.online
Hypothesis
Lightweight domain-specific data schemas, plus a vision model, can simplify multi-season plant tracking and micro-climate scheduling for home growers.
Result so far
Live, with a no-account demo garden. 640+ merged pull requests, 990+ tests, 80% line coverage enforced in CI. Built with a four-persona team of AI coding agents I directed, plus one human iOS collaborator.
Stack
Next.js, PostgreSQL with Prisma, Tailwind CSS, Google Cloud Run, GitHub Actions, Claude vision

Top five

  1. Photo to health score. Claude vision identifies the plant, scores it 0 to 100, names the issue and the next action.
  2. Priority alerts. Critical and high plants surface first, with email and SMS, plus a weekly plan from garden state and weather.
  3. Garden map and walk. Zones on a top-down photo, and a walkthrough video that identifies every plant it sees.
  4. Sunlight and shadow. Sun profile per garden, hour-by-hour shadow overlay, seasonal view.
  5. Irrigation. Watering lines, multiple schedules, dripper assignments per plant.

Shuttler: badminton match analysis

Computer vision and match-analytics prototype from one phone clip.

Hypothesis
Rally structure, tempo, player movement and a running score can be extracted from standard single-camera phone video, with no specialized tracking hardware.
Result so far
Shuttle detection 0.992 on clean footage. Rally recall 0.73 through a vision-language model where the geometry pipeline scored 0.00. 1,184 tests. Eight probes, replicated at a second venue, showed ordinary footage does not record the shuttle near contact, so landing, line calls and winner stay held and the report says so. Privacy in the product is fail-closed: blur-when-unsure for minors, and raw video never served to share-link viewers. Invite-only beta on Cloud Run. Private repository.
Stack
Python, OpenCV, TrackNet shuttle tracking, YOLO player tracking, vision-language rally segmentation, Cloud Run
