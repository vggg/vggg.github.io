Barony

Git-native policy enforcement for AI coding agents.

Hypothesis
As multi-agent coding workflows scale, enterprise teams need git-native policy enforcement, persona charters and divergence tracking, not black-box prompt chains.
Result so far
A spec, a CLI called baron, and adapters for Claude Code, code-puppy and pydantic-ai. baron guard blocks denied actions before the tool runs, and every rule is labelled honestly as enforced or merely instructed. The first-party audit that motivated it measured 0.53 operational fidelity on a real pilot, with 18 of 40 handoffs left open. Published on PyPI. Barony now governs its own repository and governed the agent teams behind TrellisIQ and Shuttler.
Stack
Python CLI (baron), git hooks, LLM guardrails, markdown and git as the substrate

enCodr

Compile ideas into visual communication.

Hypothesis
A presentation is a compiled communication product. If the argument lives in reviewable structured source (claims, evidence, dependencies, the decision being asked for), one source can compile into a ten-minute leadership briefing or a forty-five-minute engineering talk, for PPTX, web, PDF or video, without rebuilding the deck by hand.
Result so far
A thesis, a visual grammar and nine ratified architecture decisions, plus a working TypeScript prototype: a deterministic compiler that lowers, verifies and emits slides, measures text against real font metrics and checks renders in Chromium; a Fastify API, thin CLI and browser editor over PostgreSQL; provider-agnostic model adapters with reserve-before-dispatch spend metering; and a hosted agent that repairs deterministically first and escalates to a model only under a frozen policy. An offline eval suite scores its defect detectors. The prototype does not yet implement the whole thesis.
Stack
TypeScript, Fastify, PostgreSQL, Playwright and Chromium, zod, OpenAI, Anthropic and OpenRouter adapters

Shuttler: badminton match analysis

Computer vision and match-analytics prototype from one phone clip.

Hypothesis
Rally structure, tempo, player movement and a running score can be extracted from standard single-camera phone video, with no specialized tracking hardware.
Result so far
Shuttle detection 0.992 on clean footage. Rally recall 0.73 through a vision-language model where the geometry pipeline scored 0.00. 1,184 tests. Eight probes, replicated at a second venue, showed ordinary footage does not record the shuttle near contact, so landing, line calls and winner stay held and the report says so. Privacy is fail-closed: blur-when-unsure for minors, and raw video never served. Invite-only beta on Cloud Run. Private repository.
Stack
Python, OpenCV, TrackNet shuttle tracking, YOLO player tracking, vision-language rally segmentation, Cloud Run
